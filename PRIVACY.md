# PathDiver Privacy Policy

PathDiver is designed to operate locally on the user's computer.

PathDiver does not intentionally collect or transmit files, file names, search queries, filesystem metadata, analytics, or telemetry to external servers.

The desktop application uses a local HTTP server bound to `127.0.0.1` for communication between the application's local interface and its local processing engine.

No cloud account or external API is required for the core functionality.

PathDiver does not sell or share user data.
